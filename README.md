# 노몬 · Gnomon

해외 ETF 밤사이 예상 가치와 매크로 지표를 한눈에 보는 웹

## 구성

- **밤낮 ETF**: 국내 상장 해외 ETF의 밤사이 예상 가치(iNAV 추정), 구성 종목별 움직임과 기여도, 아침 브리핑, 내 계좌, 실적·발사 일정, 분배금
- **매크로 지표**: 물가 · 고용·경기 · 금리·유동성 · 시장 4개 분류의 19개 지표, 구간 설명, 그래프, 연관성 지도, 한국 시간 발표 일정

## 지금 상태

- 프로토타입 단계예요. 화면의 숫자는 대부분 **샘플**이고, 실제 데이터 연결은 진행 중이에요.
- 파일은 `index.html` 하나로 되어 있어요.

## 안내

이 앱은 정보를 보여주는 용도이며 투자 권유가 아니에요. 추정값과 해석은 실제와 다를 수 있어요.


## 품질 검사 (QA)

- `qa/run_qa.py` — 앱을 실제 브라우저로 열어 모든 화면(밤·낮, 시간대, 휴대폰·PC 크기), 지표 시트, 계산기(이상한 입력 포함), 시작 화면 전환, 데이터 점검기를 검사해 `qa-out/report.md`와 캡처를 만든다. 앱 파일은 수정하지 않는다.
- `qa/REVIEW_GUIDE.md` — AI 검토 기준서. AI는 찾고 제안만 하며 저장소를 수정하지 않는다.
- `qa/DECISIONS.md` — 이미 정한 디자인·내용 결정.
- `.github/workflows/qa.yml` — push마다, 그리고 매주 토요일 아침 08:17에 자동 검사. AI 검토는 매주 토요일 08:49 (예약 작업).
