# 노몬 사고 대응 계획 (2026-11-16)

뚫렸거나 이상할 때 **누가, 무엇을, 어떤 순서로** 할지 미리 정해 둔 문서예요. 대표님은 Claude에게 "긴급 정지해 줘", "키 바꿔야 해", "되돌려 줘"처럼 말씀만 하시면 돼요.

## 0. 공통 순서

1. **멈추기**: 피해가 커지지 않게 먼저 멈춰요 (아래 긴급 정지).
2. **알리기**: Conrad가 대표님께 긴급 알림. 게시판에 "사고" 항목으로 시각·증상·한 일을 적어요.
3. **원인 찾기**: 무엇이 언제부터 바뀌었는지 (Argus 기록, Cloudflare 로그, GitHub 변경 기록).
4. **고치기·되돌리기**: 대표 승인 뒤에 고쳐요. 되돌리기는 언제든 가능해요.
5. **다시 열기**: 대표 승인 뒤 정지를 풀어요.
6. **교훈 남기기**: `ops/LESSONS.md`에 원인과 막는 법을 적어요.

## 1. 긴급 정지 스위치 (실시간 서버)

정지하면 상태 확인(/health) 말고 서버가 모두 멈춰요. **앱은 계속 열려요.** 실시간 시세 대신 GitHub에 저장된 숫자(최대 몇 시간 전)로 보여요.

| 방법 | 어떻게 | 얼마나 |
|---|---|---|
| Claude에게 말하기 | "긴급 정지해 줘" → `ops/LOCKDOWN` 파일을 1로 올림 → 자동 배포 | 풀 때까지 계속 |
| 휴대폰 GitHub 앱 | gnomon → Actions → "실시간 서버 배포" → Run workflow → lockdown 체크 | 다음 자동 배포(평일 08:07) 전까지 |

- **푸는 것**은 대표 승인 뒤에만 해요: `ops/LOCKDOWN`을 0으로.
- Conrad는 보안 경보가 사실로 확인되면 대표 답을 기다리지 않고 정지할 수 있어요(되돌릴 수 있는 방어 조치라서). 정지하자마자 긴급 알림을 보내요.
- Argus가 정지 상태를 10분마다 확인해서 알려요.

## 2. 상황별 대응

### A. 키가 샜다는 의심 (Finnhub · 한국투자증권 · Cloudflare · GitHub)
1. 그 회사 홈페이지에서 **키를 바로 해지**해요 (대표님이 직접. 한국투자증권은 KIS Developers → 앱키 해지/재발급).
2. 새 키를 받아 **GitHub Secrets에 다시 넣기** (대표님이 직접. 채팅에는 절대 붙여 넣지 않아요).
3. Claude가 "실시간 서버 배포"를 다시 실행 → 새 키 적용 확인.
4. 한국투자증권 키였다면: 노몬 전용 빈 계좌인지 확인, 그 계좌의 주문·체결 내역 확인.
5. 어디서 샜는지 찾기: `scripts/secret_scan.py`, GitHub 비밀 검사 알림, 최근 변경 기록.

### B. 서버가 공격받는 것 같음 (보안 경보, 느려짐, 시세 사용량 급증)
1. 긴급 정지 (1장).
2. Cloudflare 대시보드 → Workers → gnomon-live → Logs에서 차단 기록(`"gnomon":"blocked"`)과 요청 수를 확인해요.
3. 원인에 맞게 고쳐요 (예: 받는 종목 목록·주소 정리). 보안 시험에 그 공격을 추가해요.
4. 대표 승인 뒤 정지 해제.

### C. 앱 화면·데이터가 이상하게 바뀜 (해킹, AI 실수, 이상한 글·링크)
1. 대표님이 "되돌려 줘" → Claude가 그 변경을 GitHub에서 되돌려요(`git revert`, 기록은 남겨요).
2. 그 데이터를 만든 AI 예약 작업을 잠시 꺼요.
3. 기사·공시 속 숨은 명령에 넘어간 경우(RULES 0-1): 그 출처를 게시판에 남기고 Scout 수집에서 빼는 것을 검토해요.

### D. GitHub · Cloudflare 계정이 털린 것 같음
1. 비밀번호 변경 → 2단계 인증 확인 → "모든 기기 로그아웃".
2. Cloudflare API 토큰 · GitHub 토큰 해지 후 새로 발급 → GitHub Secrets 다시 넣기.
3. 최근 커밋·배포·Secrets 변경 기록 확인 (GitHub → Settings → Security log).
4. 저장소가 망가졌으면 **백업**(3장)에서 되살려요.

### E. AI가 이상하게 행동함 (규칙에 없는 일, 수상한 링크, 다른 파일 수정)
1. 그 AI의 예약 작업을 꺼요 (Claude에게 "OO 멈춰 줘").
2. 그 AI가 바꾼 것을 되돌려요.
3. 원인(어떤 글을 읽고 그랬는지)을 찾아 지시문·규칙을 고쳐요 (대표 승인).

**되살리는 법** (Claude가 해요): `git clone 노몬-백업-날짜.bundle gnomon` → 내용 확인 → 새 저장소에 올리기.
GitHub 계정이 통째로 막혀도 바탕화면 백업으로 앱·데이터·규칙을 모두 되살릴 수 있어요.
