# 대표 대화 기록 (대표가 Claude 와 직접 나눈 대화에서 정한 것)

Conrad 는 실행 때마다 이 파일의 최근 72시간을 먼저 읽고 따른다. 대표 대화 내용 전체를 옮기지 않고, 팀이 알아야 할 결정만 짧게 적는다. 개인정보(메일 주소·계좌 번호 등)는 적지 않는다.

## 2026-11-17

- 한국투자증권(KIS) Open API 연결 완료. 키 만료 2027-11-16. 미국 주식은 주간거래·프리마켓·정규장·애프터마켓 모두 KIS 가 1순위, Finnhub 은 백업·교차 확인. KIS 시세는 KIS 답(재배포 가능 여부)이 오기 전까지 공개 화면에 쓰지 않음(개인 테스트만).
- 속도: 서버가 2분마다 미리 받아 두는 묶음(/snap) + 보고 있는 ETF 20초마다 새로고침 적용. 1초 실시간(웹소켓)은 KIS 답이 올 때까지 보류. Cloudflare 유료(월 약 $5)는 공개할 때.
- 앱 화면: 「나머지 종목」 줄에 프리마켓·주간·선물 몫 표시, 관전 포인트·「다음 발표에서 같이 볼 것」 왼쪽 작은 이름표(A 디자인) — 대표 승인, 반영 완료.
- 승인 대기 8~13번 모두 승인(처리 내용은 conrad.md C-20261117-0901-1).
- 대표 지시: 아침 브리핑·회의록 PDF 는 말하지 않아도 매일 아침 대표 컴퓨터 GNOMON 폴더(보고서·회의록)에 올라가야 한다. 폴더 정리 작업이 컴퓨터가 꺼져 멈추면 Conrad 가 다시 켠다.
- 승인 대기 1번(자동 작업이 sec.gov 등 웹 페이지를 열 수 있게)은 대표님이 직접 설정할 일 — 대표 대화에서 방법 안내.
